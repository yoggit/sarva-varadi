Sarva-VaradiUniversal Test Reporting

Single self-contained HTML file. No server. No database. Works with Playwright, Selenium, RestAssured, Cucumber & Robot Framework.

Quick Start →
Live Demos
📊

6 interactive sections

Overview, Failures, Tests, Trends, Timeline, and Run History — all navigable from a sidebar, with dark/light theme.

🕐

Browse any historical run

The Run History tab lists every past run. Click any row and every chart — Overview, Failures, Trends, Timeline — re-renders in-place.

🔥

Flaky test detection

Automatic flaky score computed across runs. Per-test history chart shows pass/fail/flaky pattern across the last 25 runs.

🥒

BDD & keyword-driven support

Native Gherkin hierarchy (Feature → Scenario → Step) for Cucumber adapters. Full nested keyword tree for Robot Framework tests — keyword type, timing, and sub-keywords all shown.

🖨️

PDF, PNG & CSV export

Print the full 6-section report to A4 PDF with page headers and TOC, download any chart as PNG, or export test data as CSV.

⚡

Zero configuration

Works out of the box. File-based history — just point a CI step at the output folder and history accumulates automatically.
